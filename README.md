## 📖 قصة الاسم والهوية (The Lore)

سُمّيت اللعبة بـ **«جَحْدَر»** استلهاماً من الفارس العربي التاريخي الشهير **جَحْدَر بن ضبيعة البكري**، الذي كان ضئيل الحجم قصير القامة، لكنه اتصف بجرأة خارقة وبأس أسطوري، فصرع الأسود الضارية وهزم أعتى الفرسان العمالقة.

في هذه التجربة، يلعب المستخدم بشخصية **الفارس الصغير جَحْدَر**، متسلحاً بترسانة أسلحة دمشقية مذهبة ومعدات كهرومغناطيسية متطورة، ليقف في وجه «عمالقة الويب» — الصفحات المعقدة، النصوص الإعلانية المزعجة، هياكل الـ SaaS الضخمة — ليُفتّت أبنيتها حرفاً حرفاً وعنصراً عنصراً وفق قوانين الفيزياء الواقعية.

## ⚡ المنصتان: كيف تعمل اللعبة؟ (Dual-Platform Architecture)

يعمل مشروع **جَحْدَر** بنموذجين متكاملين:

```text
                               ┌───────────────────────────────────────────────┐
                               │           جَحْدَر — JAHDAR ENGINE            │
                               └──────────────────────┬────────────────────────┘
                                                      │
                       ┌──────────────────────────────┴──────────────────────────────┐
                       ▼                                                             ▼
     [ 1. إضافة المتصفح (Browser Extension) ]                     [ 2. منصة الويب (Next.js Web App) ]
      • تعمل مباشرة داخل أي موقع مفتوح بالمتصفح                      • بيئة رمل مستقلة لتجربة الروابط
      • قراءة الـ DOM الحي بعد اكتمال تنفيذ JavaScript              • معمل محرك متكامل (Game Lab [L])
      • تتجاوز حمايات CORS و X-Frame-Options                        • فحص وتخصيص فيزياء الحركة والأصوات
      • واجهة معزولة بالكامل داخل Shadow DOM                         • دعم الأجهزة المكتبية والمحمولة
```

### 1. إضافة المتصفح الرسمية (Browser Extension - Manifest V3)
* **تدمير أي موقع بالإنترنت:** افتح أي موقع (حتى المواقع المعقدة المبنية بـ React أو Next.js أو Vue، وحتى الصفحات التي تتطلب تسجيل دخولك كبريدك أو حساباتك).
* **قراءة الـ DOM الحي (In-Situ):** يستخرج المحرك الإحداثيات الحقيقية المجهزة عبر محرك المتصفح نفسه (`getBoundingClientRect` و `Range API`)، محافظاً على التشكيل العربي، الخطوط الأصلية، وتنسيقات Flexbox و Grid.
* **عزل الواجهة (Shadow DOM):** تُحقن أزرار اللعبة وشريط الأسلحة ومؤشرات النقاط داخل `Shadow Root` مستقل تماماً، مما يمنع تعارض ملفات الـ CSS الخاصة بالموقع مع واجهة اللعبة.

### 2. منصة الويب المستقلة (Standalone Web App)
* خادم Next.js 15 يوفر بيئة لعب فورية عبر المتصفح لأي رابط، مع ميزة معمل الأسلحة والفيزياء (`Game Lab`).

## 🎯 نظام الإطلاق الموقعي المباشر (Point-Target "TO" System)

على عكس ألعاب التصويب التقليدية التي تطلق في "اتجاه عام" (`toward`) مما يؤدي لتجاوز الرصاص للمسافة المطلوبة أو حدوث خطأ زاوية (Parallax):

* **تطابق خط الرؤية (Zero Parallax):** ينطلق مسار المقذوف من فوهة السلاح ومفصل الكتف ليمر حتماً بمركز مؤشر الفأرة (Crosshair).
* **تفجير مباشر عند الهدف (Airburst & Proximity Detonation):** الصواريخ والقنابل تعلم إحداثيات الهدف؛ فإذا اعترضها جدار تنفجر فوراً، وإذا وصلت لموقع المؤشر في الفراغ أو على حافة العنصر تُفجّر الموقع المحدد بدقة.
* **ثبات الوقوف فوق المنصات (Terrain Ground Snapping):** تم تزويد المحرك بتقنية التقاط الأسطح المتكسرة بخمس نقاط ارتكاز، مما يمنع انزلاق الشخصية أو تعثرها عند الجري والقفز فوق خطوط النصوص والبطاقات المفتتة.

## 🎮 أزرار التحكم والتشغيل (Controls)

| المفتاح | الوظيفة |
| :--- | :--- |
| **A / D** أو **← / →** | التحرك يميناً ويساراً (مع تسارع وسلاسة حركية) |
| **W** أو **Space** أو **↑** | القفز (يدعم القفز المزدوج والقفز الحركي Flip) |
| **Space (بالجو)** | تشغيل الحقيبة النفاثة التكتيكية (Jetpack) للطيران |
| **S** أو **↓** | الهبوط عبر المنصات الرقيقة (Platform Drop-through) |
| **زر الفأرة الأيسر (LMB)** | إطلاق السلاح المجهز مباشرة نحو إحداثيات المؤشر |
| **زر الفأرة الأيمن (RMB)** | قذف قنبلة يدوية باليستية (أو أمر المسيّرة بالانقضاض الانتحاري) |
| **1 - 9 و 0** أو **عجلة الفأرة** | التبديل الفوري بين الأسلحة العشرة |
| **H** أو **C** | **النمط السينمائي (Cinematic Mode):** إخفاء جميع عناصر الواجهة للتصوير النظيف |
| **L** | فتح معمل المحرك (Game Lab) لتعديل الفيزياء والأسلحة والـ Skins |

## 🚀 التثبيت والتشغيل السريع (Quick Start)

### أولاً: تثبيت إضافة المتصفح (Chrome / Edge / Brave)

1. حمّل المستودع أو قم بعمل Clone له:
   ```bash
   git clone https://github.com/bio-colab/WTFunny.git
   cd WTFunny
   ```
2. افتح متصفحك وتوجه إلى إدارة الإضافات:
   * في **Chrome**: اكتب في شريط العناوين `chrome://extensions`
   * في **Edge**: اكتب في شريط العناوين `edge://extensions`
3. فعّل **وضع المطور (Developer Mode)** في الزاوية العلوية.
4. انقر على **تحميل حزمة غير مضغوطة (Load Unpacked)**.
5. اختر مجلد `extension` من داخل المشروع.
6. مبروك! افتح أي موقع واضغط على أيقونة **جَحْدَر** لبدء التدمير فوراً! 💥

---

### ثانياً: تشغيل منصة الويب محلياً (Next.js Web App)

```bash
# 1. تثبيت الحزم
npm install

# 2. بناء الإضافة
npm run build:extension

# 3. تشغيل السيرفر المحلي
npm run dev
```

افتح المتصفح على [http://localhost:3000](http://localhost:3000) واستمتع باللعب.
