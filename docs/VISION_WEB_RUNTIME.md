# 🌐 رؤية محرك جَحْدَر: من لعبة ويب إلى بيئة تشغيل ألعاب الويب الحية
## The Web-to-Game Runtime Architecture & Vision

> **«إن الفكرة ليست مجرد بناء زاحف ويب (Crawler) داخل لعبة، بل تحويل الزاحف إلى طبقة إدراك دلالي وهضم شامل لبنية الإنترنت قبل تحويلها إلى عالم فيزيائي حي.»**

---

## 🧭 الفلسفة الجوهرية (The Core Thesis)

في الألعاب التقليدية، يُصمم المطور المرحلة مسبقاً (Handcrafted Level Design).  
في **«جَحْدَر // WTFunny»**، كل صفحة وموقع وتطبيق على شبكة الإنترنت هو **مرحلة قابلة للتوليد اللحظي واللعب والاستكشاف والتدمير**.

المنظومة تتجاوز فكرة "التقاط صورة لشاشة الموقع" لتتحول إلى **Web-to-Game Runtime**:

```text
       شبكة الإنترنت (The Live Web)
                    │
           ┌────────▼────────┐
           │ Web & AI Crawler│ (طبقة الاستكشاف والدلالات)
           └────────┬────────┘
                    │
       ┌────────────┼────────────┐
       ▼            ▼            ▼
   HTML/DOM      CSSOM      Assets & State
       │            │            │
       └────────────┼────────────┘
                    │
           ┌────────▼────────┐
           │ Browser Runtime │ (محرك التخطيط الحقيقي)
           └────────┬────────┘
                    │
       ┌────────────┴────────────┐
       ▼                         ▼
Visual World             Semantic & Physics World
(رندر متصفح فائق الدقة)   (شبكة فوكسل + بوابات وميكانيكا)
       │                         │
       └────────────┬────────────┘
                    │
           ┌────────▼────────┐
           │ JAHDAR MULTIVERSE│ (عالم لعب تفاعلي لا نهائي)
           └─────────────────┘
```

## 🏛️ ركائز المعمارية المتقدمة (Core Architectural Pillars)

### 1. معمارية الطبقات الثلاث (Three-Tier Architecture)
بدلاً من حشر كل تفاصيل الويب في كنفاس واحد، ينقسم المحرك إلى ثلاث طبقات متناغمة:
1. **الطبقة البصرية (Visual Tier):**  
   استغلال رندر المتصفح الحقيقي لرسم الظلال المركبة (`box-shadow`)، التدرجات المعقدة، والتحويلات الهندسية بدقة 100%.
2. **الطبقة الفيزيائية (Physics Tier):**  
   شبكة الفوكسل النقطي 2 بكسل، مع التدمير البولياني (Boolean Subtraction)، وجاذبية الشظايا والركام، وتماسك الكلمات العربية.
3. **الطبقة الدلالية (Semantic & Mechanics Tier):**  
   تحويل وسوم الـ HTML وعلاقات الـ DOM إلى ميكانيكا ألعاب حية:
   - **الروابط (`<a href>`):** ليست نصوصاً جامدة، بل **بوابات زمكانية (Dimensional Portals)** تنقل اللاعب إلى الصفحة التالية في الموقع.
   - **الأزرار (`<button>`):** مفجرات تكتيكية ومنصات تنشيط تفاعلية (Triggers).
   - **العناوين الرئيسية (`<h1> - <h3>`):** أسقف وحصون عالية الصلابة والمقاومة (Fortified Roofs).
   - **المقالات والفقرات (`<article>, <p>`):** تضاريس ومنصات سير وركض قابلة للتكسير (Platform Terrain).
   - **الصور والوسائط (`<img>, <video>`):** كتل ثقيلة صلبة تتفتت بكتلة حركية ضخمة (Heavy Objects).
   - **الإعلانات و (`<iframe>`):** صناديق خردة قابلة للانفجار السريع (Volatile Junk).

---

### 2. الروابط كبوابات: الويب كأطلس عوالم مترابط (Links as Portals)
عند تصفح موقع ضخم مثل ويكيبيديا أو موقع إخباري:
- الصفحة الأولى تمثل **الغرفة الأولى في المتاهة (Dungeon Chamber 1)**.
- إطلاق النار على رابط مثل `[بغداد]` أو الوقوف عنده يفتح بوابة دائرية تسحب اللاعب وتولد صفحة بغداد كغرفة تالية فوراً.
- يصبح الموقع الإلكتروني بأكمله خريطة مغامرة متفرعة متعددة المستويات (State Graph Game World).

---

### 3. الزاحف التفاعلي للمواقع الحديثة (Dynamic State Crawler)
المواقع الحديثة (React, Vue, SPAs) لا تضع كامل بياناتها في كود الـ HTML الأولي:
- استخدام محرك أتمتة خفي (مثل **Playwright / Headless Chromium**) يتيح للزاحف:
  - محاكاة التمرير للأسفل (Infinite Scroll) لاكتشاف المحتوى الكسول (Lazy-loaded Content).
  - النقر على التبويبات (Tabs & Dropdowns) لتسجيل الحالات التفاعلية المختلفة (Interactive States).
  - بناء **Web State Graph** يربط كل حالة تفاعلية كعقدة في عالم اللعبة.

## 🚀 خارطة الآفاق الثلاثة (The Three Horizons)

| الأفق | الوصف | الحالة |
| :--- | :--- | :--- |
| **الأفق الأول (Horizon 1)** | محرك فوكسل 2px لتدمير صفحة واحدة بنصوص متجهة وترسانة أسلحة كاملة وهوية «جَحْدَر». | **مكتمل 100% ومرفوع على المستودع** |
| **الأفق الثاني (Horizon 2)** | زاحف هضم الموارد المحلية + تحويل الروابط لبوابات (`<a>` as Portals) وتوليد المستويات المتتابعة. | **قيد البناء والتطوير** |
| **الأفق الثالث (Horizon 3)** | زاحف تفاعلي شامل (Playwright) + فهم دلالي بالذكاء الاصطناعي لتصنيف عناصر الويب وتحويل أي موقع في العالم لعالم لعبة حي. | **الرؤية المستقبلية المفتوحة للمساهمات** |
